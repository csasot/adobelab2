# alt-row

Custom **custom** block. Purpose: Stack of full-bleed photo rows with a dark side gradient and a white text column.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per photo row: photo cell | text cell (h2 with <em> for the blue word, paragraphs, bold CTA link); cell order sets the text side.
