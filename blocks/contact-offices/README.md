# contact-offices

Custom **custom** block. Purpose: Blue offices band with white address cards and an office-hours note.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per office (one paragraph, lines split by <br>: bold office name, company, street, city, tel link, mailto link), then a last note row with office hours and Rep Locator link.
