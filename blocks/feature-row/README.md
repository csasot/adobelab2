# feature-row

Custom **columns** block. Purpose: Bordered white row with a framed photo beside a text column.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: photo | text (h2, paragraphs, bold CTA link); cell order sets the photo side.
