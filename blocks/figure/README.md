# figure

Custom **custom** block. Purpose: Article image set apart from the text flow, with optional caption and optional wrapping text.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row: cell 1 = picture + optional caption paragraph(s); optional cell 2 = text that wraps beside a left/right figure. Also supports width-<n> and pad-bottom-<n> option classes.

## Supported variations

| Variation | Option class |
| --- | --- |
| Float left | `left` |
| Float right | `right` |
| Align start | `start` |
| Align end | `end` |
| Half width | `half` |
| Thumbnail frame | `thumbnail` |
| Line after | `line-after` |
