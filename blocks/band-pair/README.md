# band-pair

Custom **custom** block. Purpose: Shared bottom bands: grey Insights band with latest post tiles plus blue Contact Omya band with the contact form.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: rows in order: Insights h2, one row per post tile (picture | date | title link), "Read Our Blog" CTA; then Contact h2, submit CTA, disclaimer paragraph. The last heading opens the contact band.
