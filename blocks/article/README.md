# article

Custom **custom** block. Purpose: Date / meta line of a single blog post, event or news item; also lays out the following default-content article body as a centred column.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell: the date (e.g. "January 15, 2024"); extra paragraphs become further meta lines. Article body is default content after the block in the same section.
